# Project Brief - ResolutionSuggester

## Core Purpose
Инструмент для оценки потери качества текстур при масштабировании. Анализирует изображения путем уменьшения их разрешения и последующего увеличения до исходного размера, после чего измеряет разницу между оригинальным и обработанным изображениями с использованием различных перцептивных метрик.

## Key Requirements

### Функциональные требования
- Анализ качества изображений при различных разрешениях
- Поддержка множества метрик (PSNR, SSIM, MS-SSIM, TDPR, LPIPS)
- Рекомендации по оптимальному разрешению на основе пороговых значений качества
- Поддержка различных методов интерполяции
- Анализ по отдельным каналам RGB/RGBA
- Визуализация зависимости качества от разрешения
- Быстрая оценка качества с использованием ML моделей
- Экспорт результатов в CSV и JSON форматы
- Поддержка русского и английского интерфейса

### Технические требования
- Поддержка Python 3.10+
- Эффективная обработка изображений
- Опциональное использование GPU через PyTorch
- Поддержка многопоточности
- CLI и GUI интерфейсы

### Поддерживаемые форматы
- EXR (.exr)
- TGA (.tga)
- PNG (.png)
- JPEG (.jpg, .jpeg)

## Current Status
Базовый функционал полностью реализован через CLI. Планируется добавление GUI для более удобного взаимодействия.

## Scope Boundaries
Основной фокус на анализе качества текстур при масштабировании, без функционала оптимизации или автоматического улучшения качества.
